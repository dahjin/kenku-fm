# Compact display mode

Enable **Compact player layout** under **Settings > Display** to fit more of
the library into smaller windows. The preference is saved and applied to the
embedded Kenku player as soon as it changes.

Compact mode narrows the Discord sidebar and browser tabs, shortens page
headers and artwork, reduces grid and card spacing, shows more library cards
per row, and uses a smaller bottom player. Playlist rows are denser, while
sound names may wrap to two lines and always expose the complete name in a
tooltip.

Comfortable mode retains the original measurements and remains the default.
